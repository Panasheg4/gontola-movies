About Gontola Movies

Built with passion for cinema and data.

The Project

Gontola Movies was built as a data analytics portfolio project during my CodeAlpha internship. It combines everything I learned — web scraping, exploratory data analysis, data visualisation and full-stack web development — into one real-world application.

The website pulls live movie data from the TMDB API, stores it in a PostgreSQL database, and serves it through a Python Flask web application — deployed on Render.

The Channel

Gontola Movies started as a YouTube channel built around a genuine love for cinema. From Top 10 rankings to iconic movie scenes and must-watch recommendations — the channel is a space for sharing the joy of movies with people who feel the same way.

This website is the natural extension of that — bringing the channel's content and recommendations into a full movie discovery platform.
